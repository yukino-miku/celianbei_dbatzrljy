# 题目理解与研究边界

## 1. 研究对象

题目研究两阶段快充策略 `C1(Q1)-C2` 对 A123 18650 磷酸铁锂电池退化的影响。SOH 为当前可用容量相对初始容量的比例，题目规定 SOH=0.8 为寿命终止阈值。

官方补充说明明确：附件只提供早期循环数据，问题一、问题二中的“循环寿命”需要根据已有 SOH 退化轨迹进行估计，而不是从 CSV 中读取真实完整寿命标签。第 150/200 次循环 SOH 与 SOH 衰减速率可作为辅助早期指标。问题三才要求使用 9 块测试电池前 150 次循环预测第 151–200 次循环及 80% SOH 寿命。

## 2. 四个问题的关系

1. 问题一建立清洗口径、早期退化表征、可解释的 SOH 外推模型和策略级寿命指标。
2. 问题二在问题一结果基础上检验充电参数与退化的关联及显著性；不能把问题一的策略组差异直接解释为参数因果效应。
3. 问题三使用训练电池模拟早期截断，建立对 9 块测试电池的时序预测流程。
4. 问题四组合寿命与充电时间模型开展多目标优化。

## 3. 当前阶段边界

本阶段只完成问题一：

- 清洗原始 SOH、容量及明显无效内阻，并保留全部原始列和异常标记；
- 从稳健重平滑曲线提取 SOH 水平、分段斜率、波动、曲率和辅助状态特征；
- 比较线性、约束二次、幂律和指数退化模型；
- 使用前 100/150 次循环拟合、预测后续已知循环，保持严格时间顺序；
- 以 SOH=0.8 求解估计寿命并分别报告条件 bootstrap 与候选模型敏感性；
- 按充电策略进行描述性汇总。

不在本阶段估计 `C1`、`Q1`、`C2` 的独立效应，也不使用 9 块测试电池的任何未来信息。
