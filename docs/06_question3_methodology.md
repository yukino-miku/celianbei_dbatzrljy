# 问题三方法

## 1. 无泄漏伪测试

对 40 块训练电池逐一作为外层目标，仅向模型暴露该目标电池 cycle 1–150，并以其真实已知的 151–200 作为验证标签；其余 39 块训练电池可使用题目提供的 cycle 1–200 完整观测，分别构造策略模板、拟合监督模型和选择参数。目标电池的未来数据同时从策略模板、监督模型、标准化、岭参数选择、集成权重和区间校准中排除。完成伪测试和模型选择后，使用全部 40 块训练电池的 cycle 1–200 重新拟合策略模板与监督模型，再预测 9 块测试电池。9 块测试电池只读取 1–150；`global_id` 不进入特征或查询。

这里的“完整观测”仅指题目提供至 cycle 200 的记录，不代表已经观测到 SOH=0.8 的真实完整生命周期。

## 2. 候选模型

- `individual_quadratic`：问题一的 constrained quadratic，仅拟合单电池 1–150。
- `local_linear`：cycle 100–150 Theil–Sen 局部斜率。
- `strategy_template`：完全同策略其他训练电池基于 cycle 1–200 的平均稳健 SOH 轨迹；最终测试预测使用全部同策略非测试电池。
- `template_individual`：在 LOBO 策略模板上，用 cycle 51–150 残差估计偏移、斜率及强正则轻度曲率修正。
- `supervised_ridge`：以前 150 次提取的 SOH50/100/150、四段斜率、曲率、波动、IR/温度/充电时间水平及趋势、策略独热变量为输入，以非目标训练电池真实 151–200 段压缩得到的线性和二次未来增量系数为监督标签；岭参数在外层训练折内部五折选择。

所有预测从 cycle 150 连续衔接并施加非增约束。监督模型只预测两个未来形状参数，没有把 50 个 cycle 当作独立标签。

## 3. 自适应集成与偏离诊断

由伪测试误差的平方倒数形成 `template_individual`、`supervised_ridge`、`individual_quadratic` 和 `local_linear` 的基础权重。训练电池的集成权重用排除目标电池后的伪测试误差计算。偏离分数综合 SOH150、100–150 斜率、IR 趋势和相对策略模板残差；偏离越大，模板权重越低，其余权重重新归一化。

测试预测区间使用 LOBO 同一预测步的绝对误差 95% 分位数，并加入模型分歧和个体偏离膨胀项。它是经验区间，不等同于已证明覆盖率的真实概率区间。

## 4. EOL

比较三种方案：仅 1–150 quadratic、加入预测 151–200 后重拟合 quadratic、同策略轻度约束后的 quadratic。训练伪测试以“真实 1–200 quadratic EOL”作为稳定性参照，而不当作真实寿命。最终方案由中位及 90% 相对变化选择。

测试 EOL 区间通过重采样完整 LOBO 未来残差轨迹 300 次获得；可靠性同时参考区间宽度、候选退化模型分歧和群体偏离。所有 EOL 都是 SOH=0.8 的模型外推指标。
