# 问题三结果与论文摘要

## 短期预测

严格 LOBO 伪测试中，自适应集成的电池平均 MAE 为 0.000277、平均 RMSE 为 0.000361、cycle 200 MAE 为 0.000522，全部 40 块电池的未来趋势方向一致。最佳单模型为局部线性，平均 RMSE 为 0.000393；集成降低约 8.2%，cycle 200 MAE 降低约 13.6%。集成最差电池 RMSE 为 0.00291，与局部线性的 0.00287 接近，因此优势主要体现在典型电池而非最坏样本。

策略层面 S1、S3、S2 最难预测，集成平均 RMSE 分别约 0.00160、0.00109、0.00079；这些策略都只有 2 块训练电池。S4–S9 中除 S9 外总体误差明显更低。LOBO 区间的平均电池覆盖率为 95.9%，但最差电池只有 48%，说明对异常个体仍可能低估风险。

## 测试电池预测

cycle 200 点预测中，B16/S8 最低，为 0.96251，95%经验区间约 [0.95947, 0.96555]；B9/S3 为 0.98213；其他测试电池约为 0.99356–0.99599。

B2/S1、B5/S2、B25/S9 的早期偏离分数分别约 2.30、2.69、4.38，被标为明显偏离。其策略模板相似度系数降至约 0.374、0.260、0.080，对应模板在最终集成中的权重约 5.8%、4.1%、1.3%。其余 6 块电池未达到明显偏离阈值。

综合同策略 LOBO 误差和个体偏离，B10/S4、B11/S5、B14/S6、B16/S8、B24/S7 的 151–200 短期预测相对可靠；B2/S1、B5/S2、B9/S3、B25/S9 可靠性较低。这里的等级仅针对短期 SOH，不等同于长期 EOL 可靠性。

## 条件性 EOL

同策略轻度约束 quadratic 在训练伪测试中相对真实 cycle 1–200 quadratic 参照的中位差约 2.82%，优于仅 1–150 的 5.07%，并略优于无群体约束的预测到 200 方案。最终测试 EOL 点估计约为：B2 1413、B5 1170、B9 657、B10 1389、B11 1532、B14 1436、B16 1003、B24 1433、B25 1468 次循环。

B16 的候选模型分歧最小，属于相对较高的条件可靠性；B11、B14 和 B25 因区间过宽或个体偏离被评为低可靠性；B9 虽 bootstrap 区间较窄，但候选模型分歧很大，只能评为中低可靠性。不能按点估计的小数精度解释寿命。

## 推荐论文表述

“在严格留一电池伪测试中，自适应集成较最佳单模型降低约 8.2% 的电池平均 RMSE。该模型结合局部趋势、constrained quadratic、同策略模板个体修正和早期特征岭回归，并对偏离同策略群体的测试电池自动降低模板权重。短期 151–200 预测具有直接验证依据；80% SOH 寿命仍为远距离模型外推，本文仅给出条件性点估计、重采样区间和可靠性等级。”
