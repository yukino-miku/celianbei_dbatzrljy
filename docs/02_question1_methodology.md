# 问题一方法说明

## 1. 早期退化特征

对每块电池在稳健重平滑 SOH 曲线上提取：

- 第 50、100、150、200 次循环附近 SOH；缺少精确循环时使用目标点 ±5 次循环的 Theil–Sen 局部线性估计；
- 1–50、50–100、100–150、150–200 和 50–200 窗口的 Theil–Sen SOH 变化率，统一换算为每 100 次循环的 SOH 变化；
- 清洗后原始 SOH 相对平滑曲线的标准差和 MAD；
- 约束二次项曲率及后段斜率相对前段斜率的变化；
- 平均充电时间、平均温度、平均内阻及其 Theil–Sen 循环趋势。

温度、内阻和充电时间在问题一中仅作辅助描述，不作因果解释。

## 2. 候选退化模型

令 `x=n/100`。所有退化系数均约束为非负，从构造上保证 SOH 随循环单调不增：

- linear：`SOH=a-dx`；
- quadratic：`SOH=a-d1*x-d2*x^2`；
- power：`SOH=a-d*x^p`；
- exponential：`SOH=a-d*(exp(r*x)-1)`。

使用 soft-L1 鲁棒非线性最小二乘。禁止高阶多项式；若 5,000 次循环内仍未达到 0.8，则记为无界/未解析，而不强制给寿命。

## 3. 时间截断验证与模型选择

对 40 块训练电池逐块执行：

1. 只用前 100 次循环拟合，预测第 101–200 次；
2. 只用前 150 次循环拟合，预测第 151–200 次；
3. 记录 MAE、RMSE、MaxAE、未来趋势符号一致性；
4. 比较同一模型用前 100/150/200 次循环所得寿命的相对变化和 0.8 阈值覆盖率。

模型综合得分由上述误差、趋势一致性、寿命稳定性、阈值覆盖率和拟合成功率的加权排名组成。随机打乱循环或普通 `train_test_split` 未被使用。

## 4. 寿命与不确定性

最终寿命定义为：

`L_hat = min{n : SOH_hat(n) <= 0.8}`。

对每块训练电池使用长度 10 的移动块残差 bootstrap，重复 300 次，得到选定模型条件下的 95% 区间。同时计算四种候选模型在前 200 次循环上的 EOL 极差相对中位数，作为结构敏感性：

- 不超过 35%：条件稳定；
- 35%–75%：中等模型敏感；
- 超过 75%：高模型敏感；
- bootstrap 有界比例不足或区间过宽时另行标记。

bootstrap 区间不包含“模型形式选择错误”带来的不确定性，因此必须与候选模型敏感性同时报告。

## 5. 策略级统计

按策略统计训练电池数、有效寿命数、可靠性类别，以及 SOH150、SOH200、50–200 衰减率和估计寿命的均值、中位数、标准差、四分位数、均值 bootstrap 95% 区间。策略代码 S1–S9 的完整名称映射写入单独表，解决长标签图中的拥挤问题。
