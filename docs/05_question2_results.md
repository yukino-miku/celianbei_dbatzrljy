# 问题二结果与论文表述建议

## 稳定结论

1. **策略整体差异存在。** 19,999 次置换检验对 SOH150、SOH200、50–200 斜率、曲率和 quadratic EOL 的 p 值分别为 0.0478、0.0196、0.00015、0.00020 和 0.00815；相应 eta-squared 为 0.387、0.482、0.794、0.748 和 0.470。Welch、Kruskal 与置换检验并不总一致，说明小组样本量与组内方差确实影响常规检验。
2. **S8 是清晰的组内异常策略。** 在 8 个可参数化策略中，S8 的 SOC 加权应力最高，SOH200 最低、50–200 斜率最负，三项均排名最差；quadratic EOL 倒数第二。S8 的快速早期退化首先由实际观测指标支持，并非只由寿命外推产生。
3. **不能把“倍率越高必然越差”作为结论。** C1 与 SOH200、斜率和 EOL 的 Spearman 方向混合，精确 p 值均大于 0.58；已有设计不支持单调、独立的 C1 伤害关系。

## 趋势性结论

1. **C2 和中高 SOC 暴露更值得关注。** 全部 8 个参数化策略中，C2 与 SOH200 的 Spearman rho=-0.699（精确 p=0.0623），与斜率 rho=-0.566（p=0.150）；第二阶段暴露与 SOH200、斜率均为 rho=-0.610（p=0.122）。方向与“中高 SOC 持续高倍率较不利”一致，但置信区间跨零。
2. **共享应力指标能描述早期退化方向。** 搜索得到 p=3.0（上边界）；应力与 SOH200、斜率的 rho 分别为 -0.587、-0.551，但精确 p 为 0.134、0.163。仅 dataset 3 的一维拟合 R² 约为 0.90，样本却只有 6 个策略，必须视为局部趋势。
3. **Q1 不能脱离倍率解释。** Q1 与 SOH200、斜率均呈正相关 rho=0.561（p=0.161），但它同时改变两阶段 SOC 区间长度，并与 C1/C2 共同构成实验策略。

## 受样本量、批次或模型结构限制的结论

- 参数化策略仅 8 个、dataset 3 内仅 6 个。全数据 C1/Q1/C2 的 VIF 为 1.37–1.51，但 dataset 3 内 C1/C2 的 VIF 升至 5.51/6.13，最大绝对相关为 0.823。
- 未控制批次的联合 OLS 中，C2 对 SOH200 和斜率的标准化系数约 -0.669/-0.665；控制批次或限制 dataset 3 后符号转正。grouped bootstrap 的全部三参数 95% 区间均跨零，说明独立系数不稳定。
- quadratic EOL 与应力的 rho=-0.060（p=0.899），没有复现 SOH200/斜率上的方向强度。凡只在 EOL 出现的关系应标为外推模型敏感；本次应力结果反而主要由观测指标驱动，长期寿命关系不稳。
- 所有 36 组策略成对比较在 Holm 校正后均未达到 0.05；这不否定全局策略差异，而是说明当前样本不足以稳定定位具体两两差异。
- batch-adjusted OLS 只有 2 个残差自由度，条件数约 10.1，不能用其表面 p 值宣称独立效应。`NEWSTRUCTURE` 与 dataset 3 完全重合，无法再单独估计结构效应。

## 推荐论文用语

“不同充电策略在前 200 次循环的 SOH 水平和退化速率上存在总体差异。S8 在实际观测的 SOH200 与稳健衰减率上均表现最差，并对应最高的 SOC 加权应力。较高 C2/中高 SOC 暴露呈更快早期退化的趋势，但该关系在批次控制与 grouped bootstrap 中不稳定。鉴于策略组合少、参数相关且策略与批次不完全可分，本文将其解释为观察性关联，不作严格因果推断；quadratic EOL 仅作为模型外推指标，并由 SOH200 和早期斜率交叉验证。”
