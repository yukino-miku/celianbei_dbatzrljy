# 统一二次退化方法

## 唯一寿命函数

四问固定使用 `SOH(n)=a-d1*n/100-d2*(n/100)^2`，且 `d1,d2>=0`。`a` 只表示初始状态或测量偏移；问题四主典型电池取 `a=1`，训练电池 `a` 分布只用于敏感性分析。EOL 取该函数首次达到 0.8 的循环次数。

## 问题一

复用已验证的数据清洗、robust LOWESS、四类候选模型与 100/150 次截断验证。显式提取 `d1,d2,R100=d1+2d2,R200=d1+4d2,A=2d2`，对每块电池做移动块残差 bootstrap，并比较 100/150/200 截断参数稳定性。可辨识性规则若发现边界或负补偿，则策略响应采用 `R100/A`，最终再转回 `d1/d2`。

## 问题二

主模型单位是 dataset 3 的 6 个策略中位数，电池用于组内方差和“先策略、后电池”的分组 bootstrap。比较标准化 raw parameters、两阶段分离暴露和求和 stress benchmark；全部用 Leave-One-Strategy-Out。S2 缺失 C1 不填补；S3/S9 作结构批次对照。早期机制变量严格来自 cycles 1–50，M0/M1/M2 按整策略留出。局部准对照用标准化参数空间距离并标记匹配质量。

## 问题三

策略先验只从排除目标电池后的训练集合得到。惩罚系数在 40 块训练电池的 1–150→151–200 伪测试中选择。若 adaptive ensemble 显著更好，短期保留 ensemble；无论短期模型为何，最终均将真实 1–150 与预测 151–200 重新拟合统一 quadratic 后求 EOL。

## 问题四

充电时间继续使用物理两阶段公式加低复杂度经验修正。寿命端不另建 stress→EOL 主模型，直接从问题二预测参数并解析求寿命。搜索域为观测矩形、凸包和最近邻信任域交集；1000 次分组 bootstrap 得到 L 中位数、P10、P90 和 95% 区间，并构造中位与 P10 双 Pareto。

## 防泄漏

不随机打乱 cycle 行；测试电池没有 cycle>150 输入；伪测试目标电池的未来数据不进入策略先验、标准化或训练；global_id 不用于查找真实寿命。
